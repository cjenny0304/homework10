# raw/｜待匯入來源材料

目前僅包含 `S01.md`…`S07.md` **原創來源導讀卡**（根據可核實的來源摘要與網站重點撰寫），不是原始論文全文，也不是完成 ingest 後的 Wiki。

正式批次 ingest 前請：
1. 優先下載 S01、S04 等開放取得全文，或取得作者／出版社允許保存的材料；其餘可以來源摘要與官方頁面為素材，但必須明示層級。
2. 如有 PDF，放在本目錄並在 `sources.json` 新增 local_file 欄位。
3. 核對 S03 correction，更正造成內容差異時更新來源卡。
4. 保留一次匯入七份的設定，並對每筆結果逐項寫入 `wiki/log.md`。
5. 若 Codex 無法存取原始網址，不得假稱已下載；以本地可追溯導讀卡做有限範圍 ingest，並明示限制。
