# Cat Language Wiki｜需求規格（已由使用者確認）

- 專案：**貓咪真的聽得懂人類說話嗎？——貓咪行為解密**（Cat Language Wiki）
- 確認方式：2026-11-23 對話中依序完成 8 題訪談，使用者已明確確認需求摘要。
- 工作原則：先討論、後生成。**本版本是新專案，不繼承先前草稿與執行紀錄。**

## 八項已確認決策
1. 讀者：一般大眾；假設沒有貓咪行為學知識。
2. 範圍：A 貓咪聽懂人話、B 肢體語言、C 情感表達、D 常見迷思、E 日常習性，五項全收。
3. 資料：正式科學研究與專業科普／動物照護／獸醫機構資料混合。
4. 來源：每筆需有來源 ID、完整標題、作者或機構、年份、原始網址；HTML 每頁顯示可追溯來源。
5. 矛盾：保留差異；比較研究對象、設計、證據強度與限制；不把爭議硬合併為單一結論。
6. Ingest：**先蒐集所有資料，一次批次 ingest**，其後逐筆驗證，不改成分批 ingest。
7. 簡報：奶油白、淺橘、暖棕可愛互動風格；10–12 頁；圖片、動畫、翻卡及小測驗；電腦手機皆可用。
8. Workflow：分階段 Graph/Loop，資料／Wiki／大綱／逐頁內容／渲染逐層檢查，只退回出錯節點。

## 交付與完成定義
- `raw/` 至少有五篇可合法使用的來源原始材料（全文、使用者提供 PDF，或足夠的合法摘要／摘錄，需明示材料層級）。
- `wiki/` 批次 ingest >= 5 筆且每筆留成功、失敗、限制與來源追蹤紀錄。
- HTML 由**完成驗證的 Wiki** 產生；每頁具 Wiki source ID；先出大綱再逐頁生成。
- 至少一次真的跑過檢查與修正，保存報告（初版、問題、回退、再驗證）。
- 程式檢查至少涵蓋來源數量、來源編號合法性、頁數與檔案存在；另外做獨立內容審查與瀏覽器人工檢查。
- 無法取得來源或核實結論時不編造；最多修正三輪，仍無法通過就標記 BLOCKED。
- `submission.md` 最後提供課堂規定的六項內容，公開 Wiki/HTML 連結須實際發布後才填。
